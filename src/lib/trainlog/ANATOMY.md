# 肌肉图

`anatomy.json` 里的身体轮廓和肌肉分区路径来自 [react-native-body-highlighter](https://github.com/HichamELBSI/react-native-body-highlighter) 3.2.0（MIT）。

头部是空白轮廓，没有五官。燃律只把路径拿来上色，没有改路径形状。
